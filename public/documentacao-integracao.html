Manual técnico completo para integração de bots, plataformas de checkout (Kiwify, Hotmart, PerfectPay) e ativação de licenças em softwares e extensões.

Autenticação Obrigatória

Todas as requisições privadas devem enviar a chave de API fornecida no cabeçalho HTTP:
Authorization: Bearer sk_live_SUA_API_KEY

1. Criar Licença após a Venda (Checkout / Bot)

Utilize esta chamada quando o cliente concluir o pagamento para gerar a chave de licença automaticamente:

POST /api/v1/licenses Gera uma nova licença ativa

Parâmetros da Requisição (JSON):

Campo Tipo Obrigatório Descrição
clientName string Sim Nome completo do cliente comprador
clientEmail string Sim Email do cliente para envio e identificação
extensionId string Sim ID da ferramenta (ex: youtube, dszap, sender, tele)
validityDays number Não (Padrão 365) Dias de validade da licença (ex: 30, 90, 365)

2. Validar Licença no Software / Extensão

Utilize no carregamento da extensão para checar se a chave do cliente é genuína, está ativa e não expirou:

POST /api/v1/licenses/verify Validação instantânea 
const res = await fetch('https://api-licencas-minhas-ferramentas.vercel.app/api/v1/licenses/verify', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer sk_live_SUA_CHAVE_AQUI'
  },
  body: JSON.stringify({
    licenseKey: 'CHAVE-DO-CLIENTE',
    extensionId: 'youtube'
  })
});

const result = await res.json();
if (result.success && result.data.valid) {
  console.log('Licença VÁLIDA! Dias restantes:', result.data.daysRemaining);
} else {
  console.log('Licença BLOQUEADA ou INVÁLIDA!');
}
curl -X POST https://api-licencas-minhas-ferramentas.vercel.app/api/v1/licenses/verify \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk_live_SUA_CHAVE_AQUI" \
  -d '{
    "licenseKey": "CHAVE-DO-CLIENTE",
    "extensionId": "youtube"
  }'

5. Sistema de Carteira Pré-Paga & Cobrança Automática (Smart Lojas Bot)

Cada revendedor possui uma carteira financeira pré-paga associada à sua API Key. A cada chamada de criação de licença via API (POST /api/v1/licenses), o valor de R$ 15,00 é debitado automaticamente do saldo disponível da carteira.

Fluxo de Integração Smart Lojas Bot:
  1. O cliente final adquire a licença no bot por R$ 30,00.
  2. O Mercado Pago confirma o recebimento do Pix no bot.
  3. O bot Smart Lojas envia uma requisição POST /api/v1/licenses autenticada com sua chave.
  4. A API valida o saldo da carteira, debita R$ 15,00, gera a licença no banco/Supabase e retorna a chave com os dados de cobrança.
  5. O bot entrega a chave ao comprador no Telegram instantaneamente.
GET /api/v1/wallet/balance Consulta o saldo atual da carteira
